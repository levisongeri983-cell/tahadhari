TAHADHARI — RETROSPECTIVE REPLAY

Tana River, April–June 2024

What a threshold on modelled river discharge would have flagged during the 2024 floods, set beside the impacts that were documented. This is a replay of past data, not a validation of the system.

How to read this page
  • The river data are GloFAS-based modelled discharge from the Open-Meteo Flood API for five locations. They are model output, not gauge readings, and they are history, not a forecast. A live system would act on forecasts with lead time; this replay does not test that.
  • Thresholds are estimated from the annual maxima of the same dataset (about the 2-, 5- and 10-year flood levels). They are not official warning levels, and the "watch" cut-off is an arbitrary illustrative choice.
  • The documented events come from OCHA, UNICEF and AFP reports. They describe county-level impacts that follow the river, and are not tied to the five towns. The comparison is qualitative, covers one flood season, and does not measure false alarms.
  • Nothing is sent. "Recommended" means what the rule-based system would route, and to whom. No agency uses this.

    Documented events and what the replay shows

    Some road closures happened while modelled river flow was still far below the 2-year level. A main-river model cannot see local flooding on small seasonal rivers, which a disaster-management officer described as the biggest gap.

    Method and limitations

    Data. Daily river discharge (m³/s) from the Open-Meteo Flood API, which is based on GloFAS, for the grid cell it selects nearest to each location. The response states which cell was used; it is shown in the summary table. The API snaps a point to the nearest model cell, which is often off the river (in a first test every town snapped to a cell with almost no flow). So the page tests the 25 model cells within about 11 km of each town and uses the one with the highest average flow in 2022–23, which should be the main channel. The chosen cell is shown in the table and should be checked on a map. Chosen cells can be 10–17 km from the town centre, and towns on the same river can show near-identical series, so agreement between locations is not independent confirmation. A cell with almost no flow is marked as not usable and no thresholds are applied to it. This is modelled history, not gauge data. Kenya Red Cross reporting describes GloFAS skill over the Tana basin as relatively low, and in November 2023 the Red Cross activated on river-gauge readings after the GloFAS forecast stayed below its trigger. This replay uses GloFAS-based data only, so treat it as a check of the approach on one dataset. Whether the model represents upstream dam operations on the Tana has not been checked.

    Thresholds. For each location, the highest value in each year from 1990 to 2023 is taken. The 2-, 5- and 10-year levels are the 50th, 80th and 90th percentiles of those annual maxima. With only a few decades of values (the count is in the table), the 10-year level in particular is uncertain. Levels: watch at 60% of the 2-year level, warning at the 2-year level, severe at the 5-year level, critical at the 10-year level. All cut-offs are editable at the top of the page script.

    What this cannot show. It cannot show that the system would have saved anyone, because the thresholds are built from the same data they are tested on and no ground truth on flood extent or timing is used. It covers one season, so it says little about false alarms; the table gives a rough base rate by counting how often severe levels occurred in the same calendar window in earlier years. Documented impacts such as camps and cholera cases lag the water and are reported for the county, so a lead time against them is only a loose indication.

    Next checks. Compare against gauge records from the Water Resources Authority if they can be obtained, test on more seasons, and discuss thresholds and alert timing with responders and residents. None of that has been done yet.
